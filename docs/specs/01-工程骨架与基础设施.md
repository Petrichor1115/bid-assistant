# Spec 01 · 工程骨架与基础设施

> 依赖：无　|　对应里程碑：M0　|　参考：[07-技术架构与工程规范.md](../prd/07-技术架构与工程规范.md)

## 1. 目标
搭好 monorepo 骨架，前后端可启动，`GET /api/health` 返回 200，统一响应/鉴权/错误中间件就绪。

## 2. 范围
- **含**：目录结构、依赖安装、Express 应用、Vite 应用、统一中间件、健康检查、环境配置、根 scripts。
- **不含**：业务路由/数据库/Agent/页面（后续 Spec）。

## 4. 关键依赖
- 后端：`express@4`、`cors`、`dotenv`、`jsonwebtoken`、`bcryptjs`、`multer`、`mysql2`、`pdf-parse`、`pdfkit`。
- 前端：`react@18`、`react-dom`、`react-router-dom@6`、`antd@5`、`@ant-design/icons`、`axios`、`zustand`、`dayjs`；dev：`vite`、`@vitejs/plugin-react`、`typescript`。

## 5. 统一中间件规范

```js
// 响应信封（controller 统一用 res.json({code:0,message:'ok',data})）
// auth.js
function auth(req,res,next){
  const h=req.headers.authorization||'';
  const t=h.startsWith('Bearer ')?h.slice(7):null;
  try{ req.user=jwt.verify(t,JWT_SECRET); next(); }
  catch{ res.status(401).json({code:401,message:'未登录或 token 无效',data:null}); }
}
function requireRole(...roles){ return (req,res,next)=> roles.includes(req.user.role)?next():res.status(403).json({code:403,message:'无权限',data:null}); }

// errorHandler.js
function errorHandler(err,req,res,next){
  const s=err.status||500;
  res.status(s).json({code:s,message:err.message||'Internal Server Error',data:null});
}
```

## 7. 验收标准
- `cd server && npm run dev` → `curl localhost:3001/api/health` 返回 `{status:"ok",db:"mysql",llm:"mock"|"ready",storage:"local"|"cloud"}`。
- `cd web-user && npm run dev`（5173）与 `cd web-admin && npm run dev`（5174）均可访问，`/api` 代理生效。
- 未带 token 访问受保护路由 → 401；错误统一信封格式。
