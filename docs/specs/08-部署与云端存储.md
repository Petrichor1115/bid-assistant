# Spec 08 · 部署与云端存储

> 依赖：Spec 01、02　|　对应里程碑：M0/M6　|　参考：[07-技术架构与工程规范.md](../prd/07-技术架构与工程规范.md) §13-14

## 1. 目标
实现 Docker 一键编排（MySQL + 后端 + 前端 nginx）、数据库自动装配、云端 dump 同步/恢复。

## 2. 范围
- **含**：`docker-compose.yml`、`server/Dockerfile`、`web/Dockerfile`、`web/nginx.conf`、`scripts/provision-db.js`、`scripts/cloud-sync.js`、`scripts/cloud-restore.js`、`services/storage/cloudStorage.js`。
- **不含**：业务代码。

## 3. 交付物
```
docker-compose.yml
server/Dockerfile、server/.dockerignore
web-user/Dockerfile、web-user/nginx.conf
web-admin/Dockerfile、web-admin/nginx.conf
server/scripts/{provision-db,cloud-sync,cloud-restore}.js
server/src/services/storage/cloudStorage.js
```

## 4. docker-compose.yml（关键）

```yaml
services:
  mysql:
    image: mysql:8.0
    environment: { MYSQL_ROOT_PASSWORD: root123456, MYSQL_DATABASE: bid_demo }
    ports: ["3306:3306"]
    volumes: [mysql-data:/var/lib/mysql]
    healthcheck: { test: ["CMD","mysqladmin","ping","-h","localhost"], interval: 5s, timeout: 5s, retries: 10 }
  server:
    build: ./server
    depends_on: { mysql: { condition: service_healthy } }
    ports: ["3001:3001"]
    environment: { DB_HOST: mysql, DB_PORT: 3306, DB_USER: root, DB_PASSWORD: root123456, DB_NAME: bid_demo,
                   STORAGE_DIR: /app/storage/uploads, STORAGE_DRIVER: local, LLM_MOCK: "true", JWT_SECRET: docker-dev-secret }
    volumes: [uploads-data:/app/storage]
    command: sh -c "node scripts/migrate.js && node seed.js && node src/index.js"
  web-user:
    build: ./web-user
    depends_on: [server]
    ports: ["8080:80"]
  web-admin:
    build: ./web-admin
    depends_on: [server]
    ports: ["8081:80"]
volumes: { mysql-data: {}, uploads-data: {} }
```

## 5. 数据库自动装配（provision-db.js）
```
1. CLOUD_DB_URL 已配置 → 直连云 MySQL，跳过本地准备
2. 否则 Docker 可用 → docker compose --project-directory .. up -d mysql
3. 否则本地 MySQL(3306) 可用 → 使用
4. 否则自动安装：Windows winget/msi、macOS brew、Linux apt/yum；启动并建 root/root123456
5. 运行 migrate 建表
```

## 6. 云端同步（cloud-sync/restore + cloudStorage.js）
- `cloud:sync`：`mysqldump bid_demo` → 压缩 → 上传云端对象存储。
- `cloud:restore`：下载最新 dump → `mysql < dump.sql`。
- `createCloudStorage()`：`s3`→`@aws-sdk/client-s3`、`oss`→`ali-oss`、`minio`→`minio`；未配置返回 null（禁用同步）。
- 依赖（server）：`@aws-sdk/client-s3`、`ali-oss`、`minio`、`mysql-client`（Dockerfile apk add）。

## 7. 验收标准
- `docker compose up -d --build` 后：用户端 `http://localhost:8080`、管理端 `http://localhost:8081` 均可访问、`/api/health` 200。
- MySQL/上传文件重建容器后数据不丢（卷持久化）。
- 无本地 MySQL 时 `npm run db:provision` 能自动拉起；配置云端后 `cloud:sync` 可上传 dump。
