# Spec 04 · 项目与文件管理

> 依赖：Spec 02、03　|　对应里程碑：M2　|　参考：[04-API接口规范.md](../prd/04-API接口规范.md)、[modules/02](../prd/modules/02-项目管理.md)

## 1. 目标
实现项目 CRUD、三件套文件上传/下载/删除、版本时间线、版本 Diff，及对手标书上传时的自动入库钩子（入库逻辑在 Spec 05 实现，此处留接口）。

## 2. 范围
- **含**：projects（7 端点）、files（4 端点）、timeline、diff。
- **不含**：对手标书入库细节、Agent 执行、审批/归档。

## 3. 交付物
```
server/src/routes/projects.js
server/src/routes/files.js
server/src/controllers/projectController.js
server/src/controllers/fileController.js
server/src/services/storage/storageAdapter.js   # save(fileBuffer,destName)->{path,url}
```

## 4. 接口规范

| 方法 | 路径 | 鉴权 | 入参 | 出参 |
|------|------|------|------|------|
| GET | /api/projects | 是 | `status,keyword,page,pageSize,sort`（sort=updated_at 供首页最近 3 用） | `{list,total,page,pageSize}` |
| POST | /api/projects | bidder | 项目字段（含 capacity_mwh/power_mw/duration_h） | `{project}` |
| GET | /api/projects/:id | 是 | - | `{project,files,library}` |
| PUT | /api/projects/:id | bidder | 项目字段? | `{project}` |
| DELETE | /api/projects/:id | bidder | - | `{message}`（级联） |
| GET | /api/projects/:id/timeline | 是 | - | `{list}` |
| POST | /api/projects/:id/files | bidder | multipart `file,file_type,version_no` | `{file,archived?}` |
| GET | /api/projects/:id/files | 是 | `version_no,file_type` | `{list}` |
| GET | /api/files/:id | 是 | - | 文件流 |
| DELETE | /api/files/:id | bidder | - | `{message}`（对手标书级联删 entry+推荐，并 -1 entry_count） |
| GET | /api/projects/:id/diff | 是 | `from,to` | `{from,to,changes,summary}` |

## 5. 核心逻辑

```js
// 上传
const {path:storage_path, url:storage_url} = storage.save(buffer, uuid+'.pdf');
insert files({id,project_id,version_no,file_type,original_name,storage_path,storage_url,file_size,uploader_id});
if(file_type==='competitor_bid') return {file, archived: await archiveService.archiveCompetitorBid(projectId,file)}; // Spec 05

// 版本语义：our_bid/announcement 跟随项目版本；competitor_bid version_no 仅作归档时点标记
// 列表筛选：status= / keyword LIKE name|bidder / 分页 page,pageSize；sort=updated_at 时按 updated_at DESC，否则 created_at DESC
// 删除项目：级联 files/agent_runs/issues/approvals/project_reports/library/entries/recommendations
// 文件限制：PDF、单文件≤50MB、对手标书≤20 份，否则 422
```

## 6. 验收标准
- 项目 CRUD + 筛选/搜索/分页正确；已归档项目编辑 → 409。
- 三件套上传成功，`/uploads/{uuid}` 可下载；非 PDF/超限 → 422。
- 上传对手标书触发入库钩子（Spec 05 联调后归档成功）。
- 删除项目级联正确；diff 对 V1/V2 我方标书字段逐项高亮。
