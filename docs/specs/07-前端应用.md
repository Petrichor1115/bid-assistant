# Spec 07 · 前端应用（用户端 web-user + 管理端 web-admin）

> 依赖：Spec 03、04、05、06　|　对应里程碑：M3　|　参考：[06-前端页面与组件规范.md](../prd/06-前端页面与组件规范.md)、[modules/*](../prd/modules/)

## 1. 目标
实现两个独立前端应用：用户端 `web-user`（对话式主页 + 项目工作台 + 11 页面）与管理端 `web-admin`（5 页面），对接全部后端接口，置灰/写死口径按 PRD。

## 2. 范围
- **含**：两应用路由、鉴权守卫、ChatLayout / WorkspaceLayout / AdminLayout、全部页面、通用组件（含 GreyedItem / TenderCard）、zustand、axios 封装、TS 类型。
- **不含**：后端逻辑。

## 5. 关键实现

- **http.ts（两应用一致）**：baseURL `/api`，请求拦截附 token，响应 `code!==0` 时 `message.error` 并 reject。
- **鉴权守卫**：无 token → `/login`；用户端仅 bidder 可访问、管理端仅 admin 可访问，否则登出回登录页。
- **ChatLayout（对话式主页 `/`）**：
  - 左导航：用户信息（头像+姓名+右侧退出按钮）；功能模块（标讯追踪/招标解读/标书生成/标书审查=置灰，竞标对比→`/workspace/projects`）；对话模块（新建对话/对话记录=置灰）；项目模块（新建项目→`/projects/new`，项目列表最近 3 个按 `updated_at` 倒序，单条→`/projects/:id`、查看全部→`/workspace/projects`，我的项目→`/workspace/projects`）。
  - 右对话框：输入框 + 上传按钮（置灰）；快捷按钮「我的项目」×2→`/workspace/projects`，其余 5 个（含竞标对比）=置灰；标讯推荐 5 张 `TenderCard` 写死、位于输入框下方靠页面底部。
  - 数据：`GET /api/projects?page=1&pageSize=3&sort=updated_at`。
- **WorkspaceLayout（项目工作台）**：二级侧边栏（仪表盘/项目列表/已归档）；进入项目后项目内导航（详情/竞标对比结果/对手标书库/版本 Diff/报告）。
- **AdminLayout（管理端）**：左侧菜单（系统仪表盘/用户管理/对话管理置灰/知识库管理置灰）+ 顶栏。
- **GreyedItem**：视觉置灰、可点击，点击 `message.info('敬请期待')`（非 disabled）。
- **TenderCard**：静态卡片（icon=SVG + name），不可点击。
- **AgentStatusBar**：轮询 `GET agent/runs`（1~2s），展示 5 主流程步骤，失败标红；离开清理定时器。
- **BidCompareResult**：4 Tab（自审问题/招标要求覆盖度/竞标差距/参数对比表）+ severity 筛选 + 对手切换下拉 + 顶部推荐卡片（采用/放弃）。
- **提交审批禁用**：最新版本 5 主流程 Agent（Agent6 除外）未全部 success。
- **埋点**：统一 `track(event,params)`（事件命名见 00-全局规范 §7）。

## 6. TS 类型（types/index.ts 关键，两应用按需取用）

```ts
type Role='bidder'|'tech_lead'|'legal'|'bid_director'|'admin';
type ProjectStatus='draft'|'in_progress'|'awaiting_approval'|'approved'|'archived'|'rejected';
type StorageType='residential'|'commercial'|'utility'|'ems_battery';
type FileType='announcement'|'our_bid'|'competitor_bid';
type AgentName='parse_announcement'|'parse_document'|'quality_check'|'requirement_coverage'|'bid_compare'|'competitor_match';
type IssueCategory='self_check'|'requirement_gap'|'bid_gap';
type Severity='red'|'yellow'|'green';
interface Project{ id:string; name:string; bidder?:string; deadline?:string; region?:string;
  storage_type?:StorageType; capacity_mwh?:number; power_mw?:number; duration_h?:number;
  description?:string; status:ProjectStatus; creator_id:string; created_at:string; updated_at?:string; }
interface Results{ version_no:number|null; opponents:{file_id:string;company_name:string}[];
  self_check:Issue[]; coverage:CoverageItem[]; bid_gaps:Issue[];
  param_compare:{fields:string[]; our:Record<string,unknown>; opponents:OpponentParam[]}; }
```

## 7. 验收标准

- 用户端 12 路由 + 管理端 5 路由可导航，无 token 跳登录，角色不符登出。
- 对话式主页：置灰项点击弹「敬请期待」；「我的项目/新建项目/竞标对比」跳转正确；标讯推荐 5 卡片静态不可点；项目列表最近 3 按更新时间倒序。
- 项目工作台二级导航正确；各页数据渲染、loading/空态/错误态齐全。
- 竞标对比结果 4 Tab + 对手切换 + 推荐采用生效；Agent 状态轮询正确；提交审批门槛生效。
- 管理端：系统仪表盘 + 用户管理可用；对话管理/知识库管理置灰弹「敬请期待」。
