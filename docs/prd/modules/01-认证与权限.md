# M1 · 认证与权限（子 PRD）

> 模块定位：系统身份认证与角色入口。MVP 仅 1 个页面。全局权限模型见 [00-全局规范](./00-全局规范.md) 第 5 节。

## 模块范围

| 项 | 内容 |
|----|------|
| 页面 | 用户端登录页（/login，固定投标专员）、管理端登录页（/login，固定 admin） |
| 接口 | `POST /api/auth/login`、`GET /api/auth/me`、`POST /api/auth/logout` |
| 依赖 | 后端 JWT 签发、5 个种子用户 |

---

## 页面 1.1 登录页（用户端 /login + 管理端 /login）

### 1. 页面核心功能说明

- 用户端登录页：输入用户名、密码（**无角色下拉，固定投标专员**）；认证成功跳 `/`（对话式主页）。
- 管理端登录页：输入用户名、密码（**无角色下拉，固定 admin**）；认证成功跳 `/admin`。
- 认证成功后签发 JWT，前端持久化 token 与 user 信息。
- 提供记住登录态（token 存 localStorage）。

### 2. 用户交互流程

```
进入 /login（用户端或管理端）
  → 填写 用户名/密码（无角色下拉）
  → 点击 [登录]
  → 前端校验必填
  → 调 POST /api/auth/login（后端按应用校验角色）
  → 成功：存 token+user → 用户端跳 `/`，管理端跳 `/admin`
  → 失败：message.error 展示后端 message，清空密码框
```

### 3. 字段与组件定义

| 字段 | 类型 | 组件 | 校验 | 必填 |
|------|------|------|------|:---:|
| username | string | Input | 非空，≤100 | ✅ |
| password | string | Input.Password | 非空，6~64 | ✅ |

### 4. 接口请求规范

| 方法 | 路径 | 入参 | 出参 | 错误码 | 时机 |
|------|------|------|------|:---:|------|
| POST | /api/auth/login | `{username,password}` | `{token,user}` | 401 | 点击登录 |
| GET | /api/auth/me | 头 `Authorization` | `{user}` | 401 | 页面刷新校验 token |

### 5. 异常场景处理逻辑

| 场景 | 触发 | 前端处理 | 兜底 |
|------|------|---------|------|
| 用户名/密码错误 | 后端 401 | message.error，清空密码 | - |
| 角色不匹配 | 后端 401 | 提示"账号与当前应用角色不匹配" | 到对应应用登录 |
| token 失效 | 任意接口 401 | 清 token → 跳 /login | 拦截器统一处理 |
| 网络异常 | 请求超时 | message.error"网络异常" | 保留表单，可重试 |

### 6. 权限控制要求

- 登录页无需鉴权；已登录访问 `/login` 时重定向到对应应用首页（用户端 `/`、管理端 `/admin`）。
- 路由守卫：无 token → 跳 `/login`；用户端仅 bidder 可访问，管理端仅 admin 可访问。

### 7. UI/UX 设计规范

- 居中卡片式布局，背景品牌色渐变；标题"标书智能审核对比系统"。
- 登录按钮全宽、loading 态；Enter 键触发提交。
- 移动端单列；错误信息红字就近展示。

### 8. 埋点需求

| 事件 | 触发 | 参数 |
|------|------|------|
| login_submit | 点击登录 | user_id=输入的用户名, app(user|admin) |
| login_success | 登录成功 | user_id, app |
| login_fail | 登录失败 | user_id, app, error_code |

### 9. 验收标准

| # | 检查项 | 预期 |
|---|--------|------|
| 1 | 正确账号 | 登录成功跳转正确（用户端 `/`、管理端 `/admin`） |
| 2 | 错误密码 | 401 提示，不跳转 |
| 3 | 无角色下拉 | 用户端固定 bidder、管理端固定 admin |
| 4 | 刷新页面 | token 有效则保持登录 |
| 5 | 无 token 访问业务页 | 重定向 /login |
