## 页面 0.1 对话式主页（/）

### 1. 页面核心功能说明
- 左侧导航 + 右侧对话框；作为进入项目工作台与竞标对比流程的统一入口。
- MVP 不实现自由对话、对话记录、对话内文件上传、知识库。

### 2. 用户交互流程
```
登录（bidder）→ 进入对话式主页 /
 → 左侧导航：
   · 新建项目 → /projects/new
   · 项目列表（最近 3，按更新时间）单条 → /projects/:id；查看全部 → /workspace/projects
   · 我的项目 → /workspace/projects
   · 竞标对比 → /workspace/projects（项目列表子页）
   · 置灰项（标讯追踪/招标解读/标书生成/标书审查/新建对话/对话记录）→ 弹 Toast「敬请期待」
 → 右侧对话框：
   · 快捷按钮「我的项目」→ /workspace/projects；其余 → 弹 Toast「敬请期待」
   · 输入框/上传按钮 → 弹 Toast「敬请期待」
   · 标讯推荐 5 张卡片 → 静态不可点
```

### 3. 字段与组件定义

| 区域 | 元素 | 组件 | 本版行为 |
|------|------|------|---------|
| 左侧·用户信息 | 头像 + 姓名 + 退出按钮 | Avatar + Text + Button | 静态展示，退出在名字右侧 |
| 左侧·功能模块 | 标讯追踪/招标解读/标书生成/标书审查 | GreyedItem | 置灰（弹「敬请期待」） |
| 左侧·功能模块 | 竞标对比 | MenuItem | 可点 → /workspace/projects |
| 左侧·对话模块 | 新建对话/对话记录 | GreyedItem | 置灰（弹「敬请期待」） |
| 左侧·项目模块 | 新建项目 | MenuItem | 可点 → /projects/new |
| 左侧·项目模块 | 项目列表（最近 3） | Menu（内嵌列表） | 单条 → /projects/:id；查看全部 → /workspace/projects |
| 左侧·项目模块 | 我的项目 | MenuItem | 可点 → /workspace/projects |
| 右侧·对话主框 | 文字输入框 | Input（置灰） | 点击弹「敬请期待」 |
| 右侧·对话主框 | 上传文件按钮 | Button（置灰） | 点击弹「敬请期待」 |
| 右侧·快捷按钮 | 我的项目（首、尾各一） | Button | 可点 → /workspace/projects |
| 右侧·快捷按钮 | 标讯追踪/招标解读/标书生成/标书审查/竞标对比 | GreyedItem | 置灰（弹「敬请期待」） |
| 右侧·标讯推荐 | 5 张卡片 | TenderCard | 写死静态，不可点 |

### 4. 接口请求规范

| 方法 | 路径 | 入参 | 出参 | 时机 |
|------|------|------|------|------|
| GET | /api/projects | `page=1,pageSize=3,sort=updated_at` | `{list,total}` | 进入（取最近 3 项目） |

### 5. 异常场景处理逻辑

| 场景 | 处理 |
|------|------|
| 项目为空 | 项目列表内嵌区空态「暂无项目」 |
| 接口失败 | 最近 3 列表置空 + message.error，可刷新 |
| 置灰项点击 | Toast「敬请期待」，不跳转 |

### 6. 权限控制要求
- 仅用户端 bidder 可见；管理端 admin 无此页面（独立系统）。

### 7. UI/UX 设计规范
- 左侧导航约 240px，分组标题（功能模块/对话模块/项目模块）。
- 置灰项视觉置灰、可点击、点击弹 Toast「敬请期待」（非 disabled）。
- 标讯推荐 5 张卡片位于输入框下方、靠近页面底部；图标为 AI 生成的 SVG 矢量占位图。

### 8. 埋点需求

| 事件 | 触发 | 参数 |
|------|------|------|
| chat_home_view | 进入 | - |
| chat_nav_click | 点导航项 | item |
| chat_quick_click | 点快捷按钮 | item |
| greyed_click | 点置灰项 | item |

### 9. 验收标准
- 置灰项点击弹「敬请期待」；「我的项目 / 新建项目 / 竞标对比」跳转正确；标讯推荐渲染 5 张静态卡片；项目列表最近 3 按更新时间倒序。
