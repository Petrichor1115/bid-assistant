# M6 · 报告与统计（子 PRD）

> 模块定位：个人工作台与项目级总结。含 2 个页面：个人仪表盘、项目总报告。

## 模块范围

| 页面 | 路由 | 核心职责 |
|------|------|---------|
| 个人仪表盘 | /workspace/dashboard | 状态卡片 / 待办 / 最近活动 |
| 项目总报告 | /projects/:id/report | 版本汇总 / 问题统计 / 耗时 / PDF 导出 |

**接口**：`GET /api/dashboard`、`GET /api/projects/:id/report`、`GET /api/projects/:id/report/pdf`、`POST /api/projects/:id/archive`。

---

## 页面 6.1 个人仪表盘（/workspace/dashboard）

### 1. 页面核心功能说明
- 我的项目状态卡片（4 类计数）、待办事项、最近活动时间线、快速入口。

### 2. 用户交互流程
```
进入 → 加载 dashboard → 点卡片跳项目列表(带状态筛选) → 点待办跳对应项目 → 快速入口新建/列表
```

### 3. 字段与组件定义

| 字段 | 组件 | 说明 |
|------|------|------|
| status_cards | 4 个 Statistic Card | draft/in_progress/awaiting_approval/archived 计数 |
| todos | List | 待跑 Agent / 待提交审批 / 待归档 派生列表 |
| recent_activities | Timeline | 最近项目/Agent 活动 |
| 快速入口 | Button 组 | 新建项目 / 项目列表 |

### 4. 接口请求规范

| 方法 | 路径 | 出参 | 时机 |
|------|------|------|------|
| GET | /api/dashboard | `{status_cards,todos,recent_activities}` | 进入 |

### 5. 异常场景处理逻辑
- 无待办：空态"暂无待办"；接口失败：卡片置 0 + 提示。

### 6. 权限控制要求
- 用户端 bidder 可见。

### 7. UI/UX 设计规范
- 卡片栅格布局（4 列）；时间线最新在上；快速入口顶部。

### 8. 埋点需求
- `dashboard_view`；`dashboard_card_click`（参数 status）。

### 9. 验收标准
- 计数正确；待办派生正确；跳转正确。

---

## 页面 6.2 项目总报告（/projects/:id/report）

### 1. 页面核心功能说明
- 项目级总结：版本时间线、每版本问题数、总耗时、问题分类统计（饼图）、最终摘要、[导出 PDF]。

### 2. 用户交互流程
```
进入 → 加载报告 → 查看图表/摘要 → 点击 [导出 PDF] → 下载 /report/pdf → 归档入口（若非 archived）
```

### 3. 字段与组件定义

| 字段 | 组件 | 说明 |
|------|------|------|
| total_versions | 文本 | 总版本数 |
| total_duration_hours | 文本 | 总耗时 |
| self_check/requirement/bid_gap 计数 | 3 个 Statistic | 问题分类计数 |
| issue_statistics_json | 饼图 | 问题分类占比 |
| version_history_json | VersionTimeline | 每版本摘要 |
| final_summary | 文本 | 最终摘要 |
| 操作 | Button | [导出 PDF]、[项目归档] |

### 4. 接口请求规范

| 方法 | 路径 | 出参 | 时机 |
|------|------|------|------|
| GET | /api/projects/:id/report | `{report}` | 进入 |
| GET | /api/projects/:id/report/pdf | 文件流 | 导出 |
| POST | /api/projects/:id/archive | `{report}` | 归档 |

### 5. 异常场景处理逻辑
- 未归档无报告 → 空态"归档后生成报告"；归档前置 status=approved，否则 409 提示。

### 6. 权限控制要求
- 全部角色可见（只读）；[项目归档] 仅 bidder/admin。

### 7. UI/UX 设计规范
- 统计卡片顶部，饼图居中，时间线下部；PDF 用 pdfkit 文字表格呈现。

### 8. 埋点需求
- `report_view`；`report_pdf_export`；`archive_click`。

### 9. 验收标准
- 统计准确；饼图正确；PDF 可下载；归档流转正确。
