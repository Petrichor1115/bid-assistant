# M7 · 管理后台（子 PRD）

> 模块定位：管理端（web-admin 独立应用）专属。含：系统仪表盘、用户管理，以及两个置灰占位菜单（对话管理 / 知识库管理，本版不实现）。扩展项（Agent 配置/历史标书库管理端/审批配置/系统设置）为 PPT 规划，MVP 不实现。

## 模块范围

| 页面 | 路由 | 核心职责 |
|------|------|---------|
| 系统仪表盘 | /admin | 项目总数 / Agent 运行次数 / 成功率 / 存储用量 |
| 用户管理 | /admin/users | 5 个种子用户列表 + 简化 CRUD |
| 对话管理 | /admin/conversations | 置灰占位（本版不实现） |
| 知识库管理 | /admin/knowledge | 置灰占位（本版不实现） |

**接口**：`GET /api/admin/dashboard`、`GET/POST/PUT/DELETE /api/users`。

---

## 页面 7.1 系统仪表盘（/admin）与用户管理（/admin/users）

### 1. 页面核心功能说明
- 系统仪表盘：项目总数 / Agent 运行次数 / 成功率 / 存储用量。
- 用户管理：5 个种子用户列表 + 新建/编辑/删除（简化 CRUD）。
- 对话管理 / 知识库管理：置灰占位（GreyedItem，点击弹「敬请期待」），本版不实现。

### 2. 用户交互流程
```
进入 → 系统统计卡片 + 用户表
 → 新建/编辑 → Modal 表单 → POST/PUT → 刷新
 → 删除 → 二次确认 → DELETE → 刷新
```

### 3. 字段与组件定义

| 区块 | 字段 | 组件 |
|------|------|------|
| 系统卡片 | project_total/agent_run_total/agent_success_rate/storage_used_bytes | 4 Statistic |
| 用户表 | name/role/department/created_at | Table + 操作列 |
| 用户表单 | name/password/role/department | Modal + Form（password 编辑时可不填） |

### 4. 接口请求规范

| 方法 | 路径 | 入参 | 出参 | 时机 |
|------|------|------|------|------|
| GET | /api/admin/dashboard | - | `{project_total,agent_run_total,agent_success_rate,storage_used_bytes}` | 进入 |
| GET | /api/users | `page,pageSize,keyword,role` | `{list,total}` | 进入/筛选 |
| POST | /api/users | `{name,password,role,department}` | `{user}` | 新建 |
| PUT | /api/users/:id | `{name?,password?,role?,department?}` | `{user}` | 编辑 |
| DELETE | /api/users/:id | - | `{message}` | 删除 |

### 5. 异常场景处理逻辑

| 场景 | 处理 |
|------|------|
| 删除自己/最后一个 admin | 后端 403/422，前端提示 |
| 用户名重复 | 后端 422 提示 |
| 密码为空新建 | 前端校验必填 |

### 6. 权限控制要求
- 仅管理端（web-admin）admin 可访问；用户端无此应用。

### 7. UI/UX 设计规范
- 卡片 + 表格上下布局；删除用 Popconfirm；表单 Modal 居中。

### 8. 埋点需求
- `admin_dashboard_view`；`user_create/submit`；`user_delete`（参数 user_id）。

### 9. 验收标准
- 统计正确；用户 CRUD 正确；权限隔离正确。
