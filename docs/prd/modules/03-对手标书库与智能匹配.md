# M3 · 对手标书库与智能匹配（子 PRD）

> 模块定位：对手标书资产归档 + 缺失时的 AI 智能匹配推荐。含 1 个页面 + 1 个跨页功能。

## 模块范围

| 项 | 内容 |
|----|------|
| 页面 | 对手标书库页 /projects/:id/library |
| 功能 | 智能匹配与对标书推荐（嵌入库页 + 竞标对比结果页推荐卡片） |
| 接口 | `GET /api/projects/:id/competitor-library`、`POST /api/projects/:id/competitor-library/match`、`GET /api/projects/:id/competitor-recommendations`、`PUT /api/recommendations/:id/adopt|dismiss` |

## 页面 3.1 对手标书库页（/projects/:id/library）

### 1. 页面核心功能说明
- 展示本项目专属对手标书库条目（公司名/行业/规模/类型/索引状态）。
- 展示智能匹配推荐列表（得分/理由/状态）。
- 提供 [智能匹配] 触发、[采用]/[放弃] 推荐操作。

### 2. 用户交互流程
```
进入 → 加载库条目 + 推荐列表
 → 点击 [智能匹配] → POST match → 刷新推荐列表
 → 点击 [采用] → 该对标书进入对比输入；[放弃] → 仅标记状态
 → 点条目可预览原始对手标书（下载）
```

### 3. 字段与组件定义

| 字段 | 类型 | 组件 | 说明 |
|------|------|------|------|
| company_name | string | 文本 | 公司名 |
| industry_domain | string | 文本/标签 | 行业领域 |
| project_scale | string | 文本 | 项目规模 |
| project_type | enum | 文本 | 储能场景 |
| index_status | enum | Tag | indexing/indexed/failed |
| match_score | number | Progress/文本 | 0~1 相似度 |
| recommendation_reason | string | 文本(可展开) | 推荐理由 |
| status | enum | Tag | recommended/adopted/dismissed |
| 操作 | - | Button | [智能匹配]/[采用]/[放弃] |

### 4. 接口请求规范

| 方法 | 路径 | 入参 | 出参 | 时机 |
|------|------|------|------|------|
| GET | /api/projects/:id/competitor-library | - | `{library,entries}` | 进入 |
| POST | /api/projects/:id/competitor-library/match | `{version_no?}` | `{recommendations}` | 点击智能匹配 |
| GET | /api/projects/:id/competitor-recommendations | - | `{list}` | 进入 |
| PUT | /api/recommendations/:id/adopt | - | `{recommendation}` | 采用 |
| PUT | /api/recommendations/:id/dismiss | - | `{recommendation}` | 放弃 |
| GET | /api/files/:id | - | 文件流 | 预览下载 |

### 5. 异常场景处理逻辑

| 场景 | 处理 |
|------|------|
| 库为空 | 空态"暂无对手标书，可上传或智能匹配" |
| 智能匹配无结果 | 空态"暂无可匹配对标书" + 上传入口 |
| 匹配中 | 按钮 loading |
| 索引 failed 条目 | Tag 红色提示"索引失败"，匹配跳过 |
| 采用已放弃项 | 按钮禁用 |

### 6. 权限控制要求
- bidder（用户端）可触发匹配与采用/放弃。

### 7. UI/UX 设计规范
- 上下两区块：本库条目表 + 推荐列表表；得分用进度条展示；采用成功 message.success + 刷新。

### 8. 埋点需求

| 事件 | 触发 | 参数 |
|------|------|------|
| library_view | 进入 | project_id |
| library_match_click | 点击智能匹配 | project_id |
| recommend_adopt_click | 采用 | project_id, source_entry_id |
| recommend_dismiss_click | 放弃 | project_id, source_entry_id |

### 9. 验收标准
- 条目与推荐正确渲染；匹配/采用/放弃流程正确；权限正确。

## 功能 3.2 智能匹配与对标书推荐（跨页）

### 1. 功能说明
- 触发条件：新建项目未上传对手标书（自动）或手动点击；基于 类型/行业/规模/技术参数 四类特征（缺哪类降级）在已有库中匹配 Top5，生成推荐理由。

### 2. 交互流程
```
触发 → 后端 Agent6 匹配 → 写 bid_recommendations
 → 库页推荐列表 + 竞标对比结果页顶部 RecommendationCard 展示
 → 采用 → 该对标书进入 Agent2/Agent5 对比输入
```

### 3. 接口
- 同 3.1（match / recommendations / adopt / dismiss）。

### 4. 异常
- 库空/全低于阈值 0.5 → 空列表；前端提示上传。

### 5. 权限 / 6. UI / 7. 埋点 / 8. 验收
- 同 3.1 对应条目；推荐卡片在竞标对比结果页的展示见 M4。
