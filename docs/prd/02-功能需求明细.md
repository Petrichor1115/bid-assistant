# 02 · 功能需求明细

> 本章定义「做什么」。每个子模块给出：核心能力、交互逻辑、输入/输出、验收标准、优先级、角色。

## 1. 模块总览

| 模块 | 名称 | MVP | 目标角色 |
|:---:|------|:---:|------|
| A | 项目管理 | ✅ | 投标专员（核心）/ 全员 |
| B | Agent 编排中心 | ✅ | 投标专员 / Admin |
| C | 用户与权限 | 🔧 简化 | Admin / 全员 |
| D | 管理后台 | 🔧/📄 | Admin |
| E | 统计报告 | ✅ | 投标专员 / 全员 |
| F | 对话式主页 | ✅ | 投标专员（用户端首页） |

优先级：P0=必须交付，P1=尽量交付。

## 2. 模块 A：项目管理

### A1 项目列表（P0，全部角色）

- **能力**：展示项目、状态筛选、搜索、分页。
- **交互**：
  - 状态筛选 Tab：全部 / 草稿 / 进行中 / 待审批 / 已归档。
  - 搜索框：按项目名 / 招标方关键字（后端 `LIKE`）。
  - 表格列：项目名、招标方、地区、储能场景、状态、截止日期、创建时间、操作（进入详情）。
  - [新建项目] 按钮 → 跳转 A2。
- **验收**：筛选 + 搜索 + 分页正确；空态展示「暂无项目」。
- **API**：`GET /api/projects`。

### A2 新建项目（P0，投标专员）

- **能力**：创建项目 + 上传三件套。
- **交互**：
  - 表单：项目名称（必填）、招标方、投标截止日期（DatePicker）、招标地区、储能场景（Select 4 选 1）、项目容量 MWh/功率 MW/时长 h（可选，供智能匹配）、项目描述。
  - 上传区：招标公告（单文件）、我方标书（单文件）、对手标书（多文件）。
  - 提交后：创建项目（`status=draft`）→ 上传各文件（`version_no=1`）→ 若上传了对手标书，后端自动归档（A8）；若未上传对手标书，后端自动触发智能匹配（A9）并返回提示。
- **验收**：必填校验；上传成功；对手标书自动归档/自动匹配提示正确。
- **API**：`POST /api/projects` + `POST /api/projects/:id/files`（对手标书归档/匹配由上传接口触发）。

### A3 项目详情（P0，投标专员）

- **能力**：项目信息聚合 + Agent 触发入口 + 版本时间线。
- **交互**：
  - 基本信息卡（可编辑，`PUT /api/projects/:id`）。
  - 文件列表（按 version_no 分组，展示 file_type、文件名、大小、上传时间）。
  - 版本时间线（V1→V2…，每版本含修改时间）。
  - 按钮区：[一键跑 Agent]（主按钮）、[智能匹配对手标书]（无对手标书时可用）、[上传新版本]。
  - Agent 执行状态条（B2）。
  - 入口：竞标对比结果、对手标书库、版本 Diff、项目总报告、提交审批。
- **验收**：各区块数据正确渲染；按钮按状态可用/禁用。
- **API**：`GET /api/projects/:id`、`GET /api/projects/:id/timeline`。

### A4 竞标对比结果页（P0，核心，投标专员）

- **能力**：4 Tab 展示分析结果 + 推荐对标书列表。
- **交互**：
  - Tab1 自审问题（category=self_check）：列表，字段/类型/当前值/严重度/建议，可标记「已解决」。
  - Tab2 招标要求覆盖度（requirement_gap）：要求项/分类/覆盖状态(✅❌⚠️)/证据。
  - Tab3 竞标差距（bid_gap）：字段/我方值/对手值/严重度/差距描述/建议；支持**对手切换下拉**（默认最新归档一份）。
  - Tab4 参数对比表：我方 vs 所选对手逐参数二维表（技术参数）；随所选对手切换。
  - 所有差距项带 🔴🟡🟢 颜色标记；支持按 severity 筛选。
  - 顶部展示「推荐对标书」卡片列表（来自 A9）：公司名/匹配得分/推荐理由/[采用]/[放弃]。
- **验收**：4 Tab 数据正确；分级颜色正确；推荐对标书可采用。
- **API**：`GET /api/projects/:id/results`、`GET /api/projects/:id/competitor-recommendations`、`PUT /api/recommendations/:id/adopt|dismiss`、`PUT /api/issues/:id`。

### A5 版本 Diff（P1，投标专员）

- **能力**：版本间修改点对比。
- **交互**：选择 V(N) 与 V(N+1)，对两版本我方标书结构化 JSON 逐字段 diff，高亮变更项（新增/删除/变更），附修改摘要。
- **验收**：diff 高亮正确。
- **API**：`GET /api/projects/:id/diff?from=&to=`。

### A6 项目总报告（P0，投标专员）

- **能力**：项目级总结 + 导出。
- **交互**：版本时间线、每版本自审问题数/差距数、总耗时、问题分类统计（饼图）、[导出 PDF]。
- **验收**：统计数字准确；PDF 可下载。
- **API**：`GET /api/projects/:id/report`、`GET /api/projects/:id/report/pdf`。

### A7 归档项目查看（P0，全部角色）

- **能力**：只读查看已归档项目。
- **交互**：已归档列表（复用 A1，status=archived 只读），查看历史版本与报告入口。
- **API**：`GET /api/projects?status=archived`。

### A8 对手标书自动归档（P0，投标专员，自动触发）

- **能力**：上传对手标书 → 自动归档至本项目专属对手标书库。
- **交互（后端自动）**：
  1. 建库检查：本项目无 `competitor_bid_libraries` 则自动创建（1:1）。
  2. 分类存储：文件存本地 `storage/uploads`，写 `files`（file_type=competitor_bid）。
  3. 元数据记录：抽取 公司名/行业领域/项目规模/项目类型/技术参数摘要 → 写 `competitor_bid_entries`。
  4. 索引建立：生成 `feature_vector` → `index_status=indexed`。
  5. 更新 `entry_count`。
- **验收**：上传后库条目 +1，元数据/索引可查。
- **API**：由 `POST /api/projects/:id/files` 触发；查询 `GET /api/projects/:id/competitor-library`。

### A9 智能匹配与对标书推荐（P0，投标专员）

- **能力**：项目无专属对手标书库时，AI 匹配同类项目对标书并推荐。
- **触发**：① 新建项目未上传对手标书（自动）；② 项目详情手动「智能匹配对手标书」。
- **交互**：基于 行业领域/项目规模/技术参数/项目类型 四类特征，在已有 `competitor_bid_entries` 中检索，返回 Top-N（含 `match_score` 与 `recommendation_reason`）；推送至 A4 竞标对比结果页。
- **验收**：返回排序正确的推荐列表；「采用」后对标书进入 Agent2/Agent5 对比输入。
- **API**：`POST /api/projects/:id/competitor-library/match`、`PUT /api/recommendations/:id/adopt|dismiss`。

## 3. 模块 B：Agent 编排中心

### B1 Agent 触发（P0）

- [一键跑全流程]：跑 5 个主流程 Agent（1→2→3→4→5）。
- 单 Agent 触发（调试）：`POST /api/projects/:id/agent/:agentName/run`。
- [智能匹配对手标书]：触发 Agent6。
- **验收**：触发后创建 agent_runs 记录，状态流转正确。

### B2 Agent 执行状态（P0）

- 状态条实时展示每个 Agent：`pending → running → success/failed`，含耗时。
- 前端轮询 `GET /api/projects/:id/agent/runs`（1~2s）。
- 细分阶段文案：排队中/解析中/抽取中/对比中/完成。

### B3 Agent 运行历史（P0）

- 每次运行完整日志（输入/输出/错误/耗时）。
- 失败项提供 [重试]：`POST /api/agent/runs/:runId/retry`。

### B4 Agent 参数配置（📄 PPT 设计，MVP 不实现）

- System Prompt 编辑、模型选择、温度/Max Token。

### B5 差距严重度阈值配置（📄 PPT 设计，MVP 不实现）

- 🔴🟡🟢 阈值可配置（MVP 用硬编码规则，见 05）。

## 6.5 模块 F：对话式主页（新增，P0）

- **能力**：用户端统一入口，左侧导航 + 右侧对话框。
- **左侧导航**：
  - 用户信息：头像 + 姓名 + 右侧退出按钮（静态）。
  - 功能模块：标讯追踪 / 招标解读 / 标书生成 / 标书审查 = 置灰；竞标对比 = 可点 → 跳项目工作台（项目列表子页）。
  - 对话模块：新建对话 / 对话记录 = 置灰。
  - 项目模块：新建项目 → 新建项目页；项目列表（最近 3 个，按更新时间，单条 → 项目详情，「查看全部」→ 项目工作台项目列表子页）；我的项目 → 项目工作台。
- **右侧对话框**：
  - 对话主框：文字输入框（置灰）+ 上传文件按钮（置灰）。
  - 快捷按钮：我的项目（首、尾各一，行为一致）→ 项目工作台；标讯追踪 / 招标解读 / 标书生成 / 标书审查 / 竞标对比 = 置灰。
  - 标讯推荐：5 张卡片（矢量 SVG 图 + 名称），写死静态不可点；5 个储能类型：户用储能 / 工商业储能 / 大型储能 / EMS / 电池包。
- **验收**：置灰项点击弹「敬请期待」；「我的项目 / 新建项目 / 竞标对比」跳转正确；标讯推荐渲染 5 张静态卡片。

## 8. 通用交互规范

- **状态标签颜色**：draft=灰、in_progress=蓝、awaiting_approval=橙、approved=绿、archived=默认、rejected=红。
- **置灰**：视觉置灰、可点击，点击弹 Toast「敬请期待」（标讯追踪/招标解读/标书生成/标书审查/新建对话/对话记录/上传按钮/快捷按钮除「我的项目」）。
- **写死**：前端硬编码静态渲染、不可交互（标讯推荐 5 张卡片）。
- **严重度颜色**：red=🔴红、yellow=🟡黄、green=🟢绿。
- **覆盖状态**：covered=✅绿、missing=❌红、not_met=⚠️橙。
- **加载态**：所有列表/按钮有 loading；Agent 运行中按钮禁用。
- **空态**：列表空展示占位文案。
- **错误提示**：统一用 AntD `message.error` 展示后端 `message` 字段。
