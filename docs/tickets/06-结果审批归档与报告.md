## T01 · resultController：results 聚合（4 类数据 + 多对手过滤）

- **描述**：聚合自审/覆盖/竞标差距/参数对比四类结果。
- **交付物**：`server/src/controllers/resultController.js`
- **要点**：
  - 默认 `version_no` = 有 success 运行记录的最大版本；无则 `version_no=null` + 空结果
  - `coverage` 从 Agent4 `output_json` 解析；`self_check`/`bid_gaps` 读 `issues` 表
  - `param_compare = {fields, our, opponents:[{file_id,company_name,params}]}`，按 `opponent_file_id` 过滤
  - 返回 `opponents` 列表供前端下拉
- **验收**：4 类数据正确；多对手按 file_id 过滤；未跑过返回 version_no=null。
- **依赖**：Spec 05（agent_runs/issues 数据）

- **验收**：筛选/分页正确；标记解决生效。
- **依赖**：T01

## T04 · approvalController：提交审批（三级自动通过）

- **描述**：实现提交审批前置校验与三级自动审批。
- **交付物**：`server/src/controllers/approvalController.js`
- **要点**：
  - `status ∈ {draft,in_progress}` 否则 409
  - 5 主流程 Agent 全 `success`（**Agent6 不纳入**）否则 422「未完成 AI 分析」
  - 生成 3 条 approvals（tech_lead→legal→bid_director，decision=approved,auto_approved=1）
  - 项目 status → `awaiting_approval` → `approved`
- **验收**：未 AI 跑通 → 422；跑通 → 三级自动通过、status=approved；非 draft/in_progress → 409。
- **依赖**：Spec 05（agent_runs）

## T06 · reportGenerator：归档统计 + 报告生成

- **描述**：归档前统计并生成 `project_reports`。
- **交付物**：`server/src/services/report/reportGenerator.js`、`server/src/controllers/reportController.js`（归档部分）
- **要点**：
  - `archive` 前置 `status=approved` 否则 409
  - 统计 total_versions/total_duration_hours/三类 issue 计数/version_history_json/issue_statistics_json
  - `final_summary` 无 LLM 用模板："项目共迭代 N 版，累计耗时 X 小时；自审 a 项、招标差距 b 项、竞标差距 c 项，其中致命 d 项。"
  - status → `archived`
- **验收**：非 approved 归档 → 409；归档生成报告、统计准确、status=archived。
- **依赖**：T01
