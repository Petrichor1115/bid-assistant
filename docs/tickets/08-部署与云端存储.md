## T01 · server/Dockerfile + .dockerignore

- **描述**：后端镜像（含 mysql-client，供 mysqldump）。
- **交付物**：`server/Dockerfile`、`server/.dockerignore`
- **要点**：`FROM node:18-alpine` + `apk add --no-cache mysql-client` + `npm install` + `COPY .` + `EXPOSE 3001`；ignore：`node_modules/storage/.env`。
- **验收**：`docker build -t server ./server` 成功。
- **依赖**：Spec 01

## T02 · web-user / web-admin Dockerfile + nginx.conf

- **描述**：两个前端应用多阶段构建（build → nginx 托管）+ 反代。
- **交付物**：`web-user/Dockerfile`、`web-user/nginx.conf`、`web-admin/Dockerfile`、`web-admin/nginx.conf`
- **要点**：`node:18-alpine` 构建 → `nginx:1.27-alpine` 托管 `dist`；`nginx.conf`：SPA 回退 + `/api`、`/uploads` 反代 `http://server:3001`（两应用同结构）。
- **验收**：`docker build -t web-user ./web-user` 与 `docker build -t web-admin ./web-admin` 成功；静态可托管、反代生效。
- **依赖**：Spec 07

## T03 · docker-compose.yml（mysql + server + web + 卷）

- **描述**：一键编排四服务 + 数据卷。
- **交付物**：`docker-compose.yml`
- **要点**：mysql（8.0，`mysql-data` 卷，healthcheck）→ server（depends_on 健康，`uploads-data` 卷，`migrate && seed && start`）→ web-user（`8080:80`）→ web-admin（`8081:80`）。
- **验收**：`docker compose up -d --build` 后 8080/8081 可访问、`/api/health` 200。
- **依赖**：T01、T02

## T04 · provision-db.js（数据库自动装配）

- **描述**：按优先级自动准备数据库。
- **交付物**：`server/scripts/provision-db.js`
- **要点**：`CLOUD_DB_URL` 直连 → Docker `compose --project-directory .. up -d mysql` → 本地 3306 → 自动安装（winget/brew/apt）→ `migrate`。
- **验收**：无本地 MySQL 时 `npm run db:provision` 自动拉起并建表。
- **依赖**：Spec 02

## T05 · cloudStorage.js（s3/oss/minio 驱动抽象）

- **描述**：云端对象存储统一接口。
- **交付物**：`server/src/services/storage/cloudStorage.js`
- **要点**：`createCloudStorage()` 按 `CLOUD_STORAGE_DRIVER` 分派 `@aws-sdk/client-s3`/`ali-oss`/`minio`；未配置返回 null；统一 `upload(key,data)/download(key)`。
- **验收**：三驱动可实例化，未配置返回 null。
- **依赖**：无

## T06 · cloud-sync.js + cloud-restore.js

- **描述**：MySQL dump 上传云端与恢复。
- **交付物**：`server/scripts/cloud-sync.js`、`server/scripts/cloud-restore.js`
- **要点**：sync = `mysqldump bid_demo` → 压缩 → `cloudStorage.upload`；restore = `download` → `mysql < dump.sql`。
- **验收**：配置云端后 `cloud:sync` 可上传、`cloud:restore` 可恢复。
- **依赖**：T05

## T07 · 部署与云端存储联调验证

- **描述**：端到端验证部署与存储。
- **交付物**：验证记录（`docs/tickets/verify-08.md`）
- **验收**（对应 Spec 08 §7）：
  1. `docker compose up -d --build` → 8080/8081 可访问、health 200
  2. 重建容器后 MySQL/上传文件数据不丢
  3. `db:provision` 能自动装配；`cloud:sync` 可上传 dump
- **依赖**：T03、T04、T06
