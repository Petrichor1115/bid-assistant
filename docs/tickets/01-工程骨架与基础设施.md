## T01 · 初始化 monorepo 根目录与 .gitignore

- **描述**：在仓库根创建 `package.json`（含 scripts 占位）、`.gitignore`，建立 `server/`、`web-user/`、`web-admin/`、`docs/` 目录骨架。
- **交付物**：
  - `package.json`（`name`、`private:true`、`scripts` 先留空，T09 补）
  - `.gitignore`（覆盖 `node_modules/`、`dist/`、`.env`、`server/data/`、`server/storage/`、`.vite/`）
- **验收**：`npm install` 无报错；`node_modules`、`.env`、`storage` 不被 git 追踪。
- **依赖**：无

## T02 · 后端工程初始化（package.json / .env.example / config.js）

- **描述**：初始化 `server/`：声明依赖与 scripts、环境变量模板、配置读取。
- **交付物**：
  - `server/package.json` — deps：`express@4`、`cors`、`dotenv`、`jsonwebtoken`、`bcryptjs`、`multer`、`mysql2`、`pdf-parse`、`pdfkit`；scripts：`dev=node --watch src/index.js`、`start`、`db:migrate`、`db:provision`、`cloud:sync`、`cloud:restore`、`seed`
  - `server/.env.example` — 完整变量（PORT/JWT_SECRET/DB_*/CLOUD_DB_URL/STORAGE_*/CLOUD_STORAGE_*/LLM_*，见 Spec 01 §6）
  - `server/src/config.js` — `dotenv.config()` + 导出规范化配置对象
- **验收**：`cd server && npm install` 成功；`config.js` 能读取 `.env` 中 `PORT`、`JWT_SECRET`。
- **依赖**：T01

## T03 · Express 应用骨架 + 静态 /uploads

- **描述**：搭建 Express 应用与 HTTP 入口，挂载 CORS、JSON 解析、静态文件。
- **交付物**：
  - `server/src/app.js` — `cors()`、`express.json()`、`express.static(STORAGE_DIR)` 挂 `/uploads`、挂载路由、末尾 404 兜底 + `errorHandler`
  - `server/src/index.js` — 读 `PORT` 启动 `app.listen`
- **验收**：`npm run dev` 启动；访问未定义路径返回 404 JSON 信封。
- **依赖**：T02

## T04 · 统一响应信封 + 错误处理中间件

- **描述**：实现统一成功/失败响应与集中错误处理。
- **交付物**：
  - `server/src/utils/response.js` — `ok(res,data)` / `fail(res,status,code,message)`
  - `server/src/middleware/errorHandler.js` — 捕获错误，按 `err.status||500` 输出 `{code,message,data:null}`
- **验收**：手动触发 400/404/500 均返回统一信封格式。
- **依赖**：T03

## T05 · 鉴权中间件（JWT + requireRole）

- **描述**：解析 Bearer token，注入 `req.user`，提供角色守卫。
- **交付物**：`server/src/middleware/auth.js` — `auth`、`requireRole(...roles)`。
- **验收**：无 token → 401；token 有效但 role 不符 → 403；通过后 `req.user={id,name,role}`。
- **依赖**：T02（需 JWT_SECRET）

## T06 · 健康检查接口 GET /api/health

- **描述**：提供探活接口，按环境返回存储/LLM/DB 状态。
- **交付物**：`server/src/routes/health.js`。
- **验收**：`curl localhost:3001/api/health` → `{status:"ok",db:"mysql",llm:"mock"|"ready",storage:"local"|"cloud"}`。
- **依赖**：T03、T04

## T07 · 前端工程初始化（Vite + React + AntD）

- **描述**：初始化 `web-user/` 与 `web-admin/`：Vite + React 18 + TS + AntD 5。
- **交付物**：
  - `web-user/package.json` 与 `web-admin/package.json` — deps：react/react-dom/react-router-dom/antd/@ant-design/icons/axios/zustand/dayjs；dev：vite/@vitejs/plugin-react/typescript/@types
  - `web-user/vite.config.ts`、`web-admin/vite.config.ts` — proxy：`/api`、`/uploads` → `http://localhost:3001`
  - `web-user/index.html`、`web-user/src/main.tsx`（web-admin 同）— 挂载 + `ConfigProvider locale=zhCN`
- **验收**：`cd web-user && npm install && npm run dev` → 5173 可访问；`cd web-admin && npm install && npm run dev` → 5174 可访问。
- **依赖**：T01

## T08 · 前端路由骨架 + 鉴权守卫 + http 封装

- **描述**：搭建用户端 12 条与管理端 5 条路由占位页、各自鉴权守卫、axios 实例。
- **交付物**：
  - `web-user/src/App.tsx`、`web-admin/src/App.tsx` — `BrowserRouter` + `Routes`
  - `web-user/src/router/index.tsx` — 12 路由 + `AuthGuard`；`web-admin/src/router/index.tsx` — 5 路由 + `AuthGuard`
  - `web-user/src/api/http.ts`、`web-admin/src/api/http.ts` — baseURL `/api`、请求拦截附 token、响应 `code!==0` 时 `message.error` + reject
- **验收**：登录后用户端落地 `/`、管理端落地 `/admin`；无 token 访问业务页重定向 `/login`。
- **依赖**：T07

## T09 · 根 scripts 一键启动（concurrently）

- **描述**：根 `package.json` 补 `concurrently`，实现一键双端启动。
- **交付物**：根 `package.json` — `dev:server`、`dev:web-user`、`dev:web-admin`、`dev`（concurrently）。
- **验收**：`npm run dev` 同时拉起 3001/5173/5174。
- **依赖**：T02、T07

## T10 · 联调冒烟测试

- **描述**：对 Spec 01 §7 三条验收做端到端验证并记录结果。
- **交付物**：冒烟记录（可附 README 或截图）。
- **验收**：
  1. `curl localhost:3001/api/health` 返回 200 正确字段
  2. 用户端 5173、管理端 5174 可访问且 `/api` 代理生效
  3. 无 token 访问受保护路由 → 401；错误统一信封
- **依赖**：T03、T04、T05、T06、T07、T08
