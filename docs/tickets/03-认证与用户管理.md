## T01 · authController：登录逻辑（login）

- **描述**：实现登录：按用户名查用户 → bcrypt 校验密码 → 按 app 校验角色 → 签发 JWT。
- **交付物**：`server/src/controllers/authController.js`
- **要点**：
  - `SELECT * FROM users WHERE name=?`
  - `bcrypt.compareSync(password, u.password_hash)` 失败 → 401「用户名或密码错误」
  - `const need = app==='admin' ? 'admin' : 'bidder'`；`u.role !== need` → 401「账号与当前应用角色不匹配」
  - `jwt.sign({id,name,role}, JWT_SECRET, {expiresIn:'7d'})`
  - 返回 `{token, user:{id,name,role,department}}`（剔除 password_hash）
- **验收**：正确账号+app 返回 token；app 与角色不符 401。
- **依赖**：Spec 02（users 表 + 种子）

## T02 · authController：me + logout

- **描述**：实现当前用户查询与无状态登出。
- **交付物**：`server/src/controllers/authController.js`（追加）
- **要点**：`me` 用 `req.user.id` 查完整 user 返回；`logout` 直接返回 `{message:"ok"}`（前端删 token）。
- **验收**：me 返回当前用户；logout 返回 ok；无 token → 401（由中间件保证）。
- **依赖**：T01

## T03 · routes/auth.js 挂载 + 鉴权接入

- **描述**：挂载 auth 三个端点，login 无鉴权、me/logout 走 `auth` 中间件。
- **交付物**：`server/src/routes/auth.js`；并在 `app.js` 注册。
- **要点**：`POST /login`（公开）、`GET /me`、`POST /logout`（均 `auth`）。
- **验收**：`curl` 登录返回 token；无 token 调 me → 401。
- **依赖**：T01、T02、Spec 01 T05（auth 中间件）

## T04 · userController：用户 CRUD

- **描述**：实现用户列表/创建/查询/更新/删除，含权限与边界校验。
- **交付物**：`server/src/controllers/userController.js`
- **要点**：
  - list：`page/pageSize/keyword(name LIKE)/role` 筛选，`created_at DESC`
  - create：重名校验（422）、`bcrypt.hashSync(password,10)`
  - get/update：404；update 密码可选（不传不更新）
  - remove：禁删自己（422）、禁删最后一个 admin（422）
  - 所有返回剔除 `password_hash`
- **验收**：admin 可完整 CRUD；重名/删自己/删最后 admin → 422。
- **依赖**：Spec 02

## T05 · routes/users.js 挂载 + requireRole(admin)

- **描述**：挂载 5 个用户端点，全部 `requireRole('admin')`。
- **交付物**：`server/src/routes/users.js`；`app.js` 注册。
- **要点**：GET/POST `/api/users`、GET/PUT/DELETE `/api/users/:id`。
- **验收**：非 admin 访问 → 403。
- **依赖**：T04、Spec 01 T05

## T06 · 认证与用户模块联调验证

- **描述**：端到端验证登录、鉴权、CRUD、权限边界。
- **交付物**：验证记录（`docs/tickets/verify-03.md`）
- **验收**（对应 Spec 03 §6）：
  1. 正确账号+app → token；app 与角色不符 → 401
  2. 无 token 调 me → 401；admin 可 CRUD；非 admin 调 users → 403
  3. 删除自己/最后 admin → 422
- **依赖**：T03、T05
