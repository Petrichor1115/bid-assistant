## T01 · 编写完整 schema.sql（10 表 + 索引 + 约束）

- **描述**：编写 MySQL 8.0 完整 DDL，含建库、10 张表、CHECK 枚举、外键级联、索引。
- **交付物**：`server/schema.sql`
- **要点**：
  - `CREATE DATABASE IF NOT EXISTS bid_demo ... utf8mb4` + `USE bid_demo`
  - 10 表：`users / projects / files / agent_runs / issues / approvals / project_reports / competitor_bid_libraries / competitor_bid_entries / bid_recommendations`（字段与约束完整见 PRD 03）
  - 主键 `VARCHAR(36)`；时间 `DATETIME DEFAULT CURRENT_TIMESTAMP`；布尔 `TINYINT(1)`；JSON 字段用 `JSON`
  - 枚举用 `CHECK`（role/status/storage_type/file_type/agent_name/category/severity/level/decision/index_status/推荐状态）
  - 外键：业务主外键 `ON DELETE CASCADE`；`bid_recommendations.source_file_id` 用 `ON DELETE SET NULL`
  - 8 个索引（files/agent_runs/issues/approvals/entries/recommendations 相关）
  - 命名统一（v3.0）：`agent_runs.agent_name` 含 `bid_compare`（非 competitor_compare）；`issues.category` 含 `bid_gap`（非 competitor_gap）；`project_reports` 含 `bid_gap_count`（非 competitor_gap_count）
- **验收**：在 MySQL 8.0.16+ 手动 `SOURCE schema.sql` 无报错，`SHOW TABLES` 显示 10 表。
- **依赖**：无

## T02 · 迁移脚本 migrate.js

- **描述**：用 `mysql2` 执行 `schema.sql` 全文（`multipleStatements:true`），支持重复执行。
- **交付物**：`server/scripts/migrate.js`
- **要点**：`createConnection({host,port,user,password,multipleStatements:true})` → `query(fs.readFileSync('schema.sql'))` → `end()`。
- **验收**：`npm run db:migrate` 建库建表成功；重复执行不报错（`IF NOT EXISTS`）。
- **依赖**：T01

## T03 · 数据库连接池 db/index.js

- **描述**：封装 `mysql2/promise` 连接池单例，供所有业务代码复用。
- **交付物**：`server/src/db/index.js`
- **要点**：`createPool({host,port,user,password,database,waitForConnections:true,connectionLimit:10,timezone:'Z'})`，导出单例。
- **验收**：`node -e "require('./src/db').query('SELECT 1')"` 返回结果。
- **依赖**：T02（需库已建）

## T04 · 种子脚本 seed.js（5 用户）

- **描述**：`users` 为空时插入 5 个种子用户，密码运行时 bcrypt 生成。
- **交付物**：`server/seed.js`
- **要点**：5 用户 role = `bidder/tech_lead/legal/bid_director/admin`，密码明文 `123456`，`bcrypt.hashSync('123456',10)` 写入 `password_hash`；幂等（已存在则不重复插）。
- **验收**：`npm run seed` 后 5 用户可查询，`bcrypt.compareSync('123456', hash)` 为 true。
- **依赖**：T02

## T05 · 示例数据种子（项目/库/条目/文件）

- **描述**：追加 1 组示例数据，供后续 Agent/演示联调（德国 50MWh 工商业储能）。
- **交付物**：`server/seed.js` 内追加（或 `server/seed-demo.js`）

- **验收**：示例数据可查，库→条目→文件外键关联正确，`entry_count=1`。
- **依赖**：T04

## T06 · 约束与级联验证

- **描述**：验证 CHECK 枚举、外键级联、JSON 字段读写，作为数据层回归基线。
- **交付物**：验证记录（`docs/tickets/verify-02.md` 或测试 SQL）
- **要点**：
  - 插入非法 `role`/`status` → 被 CHECK 拒绝
  - 删除项目 → 级联删除 files/agent_runs/issues/approvals/project_reports/library/entries/recommendations
  - 写入/读取 `JSON` 字段正常（mysql2 自动序列化）
- **验收**：上述三条全部通过。
- **依赖**：T01~T05
