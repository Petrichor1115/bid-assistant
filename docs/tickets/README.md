## 3. 并行开发提示

- **M2**：Spec03（认证）与 Spec04（项目/文件）完全并行，均只依赖 M1 数据层。
- **M4**：Spec05 主线（T01→T07）与入库/匹配（T08/T09）、mock（T10）可三线并行；Agent1/2/5（T03/T04/T06）互不依赖可并行。
- **M3**：前端 T01/T02（底座）在 M2 完成后即可启动，不等 M4/M5；页面按组（T03~T09）可多人并行。
- **M6**：部署联调依赖全部业务接口就绪。

## 4. 票据规范

每张票据固定包含四要素：

| 要素 | 说明 |
|------|------|
| **描述** | 做什么（一句话 + 要点） |
| **交付物** | 具体文件路径 |
| **验收标准** | 可执行命令/可观察行为 |
| **依赖** | 前置票据 ID 或 Spec |

执行约定：单票粒度以「1 个 AI 会话可独立完成并验收」为上限；跨票交付物不重叠。
