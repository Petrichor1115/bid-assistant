## T01 · 基础设施：http/types/store/router/守卫/三布局

- **描述**：搭建两应用底座：API 封装、类型、状态、路由、鉴权守卫、布局。
- **交付物**：
  - `web-user/src/{api/http.ts, types/index.ts, stores/{authStore,projectStore}.ts, router/index.tsx, App.tsx}`
  - `web-user/src/layouts/{ChatLayout,WorkspaceLayout}.tsx`
  - `web-admin/src/{api/http.ts, types/index.ts, stores/authStore.ts, router/index.tsx, App.tsx}`
  - `web-admin/src/layouts/AdminLayout.tsx`
- **要点**：
  - `http.ts`：baseURL `/api`，请求拦截附 token，响应 `code!==0` → `message.error` + reject
  - 守卫：无 token → /login；用户端仅 bidder、管理端仅 admin，否则登出
  - ChatLayout：左导航（用户信息/功能模块/对话模块/项目模块）+ 右对话框；WorkspaceLayout：二级侧边栏（仪表盘/项目列表/已归档）；AdminLayout：左菜单 + 顶栏
  - TS 类型对齐 Spec 07 §6（含 `Results`/`CoverageItem`/`OpponentParam`/`bid_gaps`/`bid_compare`）
- **验收**：用户端 12 路由、管理端 5 路由可导航、无 token 跳登录、角色不符登出。
- **依赖**：Spec 01（前端骨架）

## T02 · 通用组件（9 个）

- **描述**：实现复用组件，含置灰/写死专用组件。
- **交付物**：`components/{StatusTag,SeverityTag,CoverageTag,FileUploader,AgentStatusBar,VersionTimeline,RecommendationCard,GreyedItem,TenderCard}.tsx`
- **要点**：
  - StatusTag/SeverityTag/CoverageTag：状态/严重度/覆盖状态颜色映射
  - FileUploader：Dragger，`accept/multiple/onChange`
  - AgentStatusBar：轮询 `GET agent/runs`（1~2s），5 主流程步骤，失败标红，卸载清定时器
  - VersionTimeline、RecommendationCard（采用/放弃按钮）
  - GreyedItem：视觉置灰、可点击，点击 `message.info('敬请期待')`
  - TenderCard：静态卡片（icon=SVG + name），不可点击
- **验收**：组件可复用，颜色/交互正确，轮询定时器正确清理，置灰弹「敬请期待」。
- **依赖**：T01

## T03 · 登录页 ×2 + 对话式主页（ChatHome）

- **描述**：两应用登录页与用户端对话式主页。
- **交付物**：`web-user/src/pages/{Login,ChatHome}.tsx`、`web-admin/src/pages/Login.tsx`
- **要点**：
  - 登录：用户名/密码（**无角色下拉**，用户端固定 `app='user'`、管理端 `app='admin'`），成功用户端跳 `/`、管理端跳 `/admin`
  - ChatHome：左导航（用户信息头像+姓名+退出按钮；功能模块 4 置灰 + 竞标对比→`/workspace/projects`；对话模块 2 置灰；项目模块新建/最近3（单条→`/projects/:id`、查看全部→`/workspace/projects`）/我的项目）；右对话框（输入框/上传按钮置灰；快捷按钮我的项目×2→`/workspace/projects`、其余 5 置灰；标讯推荐 5 张 TenderCard 写死）
  - 最近 3 项目：`GET /api/projects?page=1&pageSize=3&sort=updated_at`
- **验收**：登录跳转正确；置灰项弹「敬请期待」；「我的项目/新建项目/竞标对比」跳转正确；标讯推荐静态不可点。
- **依赖**：T01、Spec 03
